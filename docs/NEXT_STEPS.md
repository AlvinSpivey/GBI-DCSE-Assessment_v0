# Next evidence before an IHS-facing evaluation

![Assessment update](application/figures/updated.svg)

This is a proposed research plan, not an approved institutional protocol or a list
of current IHS requirements.

| Work package | Evidence needed | Stop condition |
|---|---|---|
| Population and provenance | Approved sites, sampling frame, independent units and source-quality assessment | Do not generalize synthetic Massachusetts results to an IHS population. |
| Model-output repair | Fixed model/prompt/version, complete outcomes, held-out tasks and separately measured format/semantic results | Do not count deterministic rendering as model reasoning success. |
| FHIR conformance | Full validator, resource invariants, terminology and the actual target implementation guide | JSON-schema success alone is insufficient. |
| Endpoint interoperability | Approved test environment, documented capabilities and authorized integration protocol | No production or patient-data writes from this review. |
| Policy validation | Named institutional and Tribal participants; versioned rules and disagreement adjudication | Faithful rule execution is not proof that a rule is appropriate. |
| Human factors and clinical validity | Approved study, intended users, expert references and measured outcomes | No clinical accuracy or safety claim without that evidence. |
| Infrastructure | Actual platforms and fault tests for any deployment features being claimed | Software models are not deployed infrastructure. |

The next model study should preserve the historical result, report abstention and
completion separately, include all attempted tasks and predefine the comparison.
The roadmap intentionally contains no invented dates, sample-size guarantee or
institutional endorsement.
