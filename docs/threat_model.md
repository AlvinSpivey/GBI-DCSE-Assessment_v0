# Review limitations and misuse cases

The main risks for this evidence-only distribution are changed denominators,
missing adverse results, confusion between model and reference-adapter outputs,
and promotion of formatting or synthetic results into clinical claims.

The local checker catches supported forms of inconsistency and file changes.
It cannot establish source honesty, verify omitted implementation, validate
institutional policy, certify patient risk, or assess a remote repository's full
history. Any coordinated alteration of records and their manifest needs external
provenance review.

Only ordinary local files are needed. The review page contains no network
requests, telemetry, remote media or source-document upload function. External
citations, if explicitly followed by the reader, open the referenced site.
