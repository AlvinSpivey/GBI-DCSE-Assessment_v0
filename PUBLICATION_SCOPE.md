# Exact scope of this review candidate

This directory is designed to be a new, independent, evidence-only repository.
It contains conventional methods descriptions and selected outcomes for GBI and
DCSE. It does not purport to be a full software distribution or a clinical product.

The current status is **private owner review**. No public-release authorization,
legal clearance, institutional endorsement or patent status is asserted. Before
changing visibility, the owner should obtain the appropriate disclosure and rights
review of the exact files, including the new prose and figures.

Keep any other development repositories separate. Do not mirror older refs, copy
an existing `.git` directory, attach internal archives or assume changing the
default branch hides history. The local checker does not inspect GitHub metadata,
branches, pull requests, Actions artifacts, releases or copies held elsewhere.

The existing software, data and documentation notices are preserved, not revoked.
Any notice that names an omitted path does not imply that file is distributed.
The included new checker is software under the retained software notice; prose
and figures follow the retained documentation notice. Later additions need a new
scope review.
